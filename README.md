# 一个基于YOLOv7的可视化检测平台

**本项目更偏向于是一个模板，可供参考**

- 可视化界面基于pyQT5实现
- 简单修改my_detect函数后，可用于其他算法的可视化（例如YOLOv5、YOLOv8等）
- 支持读取本地图片、视频、摄像头
- 支持可视化修改权重文件Weights
